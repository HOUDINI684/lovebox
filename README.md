# LOVEBOX

Plateforme de cadeaux emotionnels digitaux pour l'Afrique francophone.

## Demarrage

npm install
cp .env.example .env
npm run dev

## Stack

React + Vite, Firebase Firestore, Cloudinary (medias), Vercel Functions (emails), Tailwind CSS, Framer Motion.
Lancement gratuit, sans paiement integre.
